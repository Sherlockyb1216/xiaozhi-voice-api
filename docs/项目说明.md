# 小智语音助手 API（xiaozhi-api）

## 项目简介
基于 FastAPI 的轻量级语音交互服务，从 xiaozhi-esp32-server 提取核心逻辑并独立部署。

## 系统架构
客户端 → /ask API → 意图识别 → LLM 对话 → TTS 语音合成 → 返回文本+语音

## 主要功能
- **文本问答**：POST /ask 接收文本，返回 AI 回复
- **意图识别**：自动识别时间查询等特定意图
- **语音合成**：返回 base64 编码的 MP3 音频

## 阶段四：AI CRM 集成

### 新增功能
- 对接 ai_crm 客户管理系统，支持意图识别 + 知识库检索
- 基于手机号的对话记忆（SQLite）
- 完整语音交互链路：语音 → 文本 → CRM → 答案 → 语音合成

### 更新接口
- POST /ask 新增 `phone_number` 参数（可选）
